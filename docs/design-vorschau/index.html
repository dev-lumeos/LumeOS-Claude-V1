Richtungen

A — Instrumententafel

WHOOP-Linie

Verdichtung statt Anzeige. Aus vielen Signalen wird eine Zahl, danach drei Stufen: Überblick, Verlauf, Detail.

B — Bento

Layout

Die Kachelfläche kommuniziert Priorität, bevor jemand ein Wort liest. Eine Layoutsprache, keine Ästhetik.

C — Liquid Glass

Tiefe

Glas trennt Ebenen ohne zusätzliche Farben. Nur für Navigation und Dialoge — kein Datenwert steht auf Unschärfe.

Buddy

Der Wochenrückblick als Erzählung in vier Kapiteln. Die einzige Variante, die einen Zusammenhang erklärt statt Werte zu zeigen.

Medizin
