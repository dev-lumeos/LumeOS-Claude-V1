# Lumeos Coach — Typische Coach-Workflows

## Workflow 1: Neuen Client onboarden

```
1. Client meldet sich an → Onboarding Form (Goals, History, Injuries, Diet, Supplements)
2. Coach reviewed Profil → Notizen
3. Optional: Client teilt Blutwerte (Medical Module)
4. Coach erstellt:
   - Training Program (4-12 Wochen, periodisiert)
   - Nutrition Plan (Macros + ggf. Meal Plan)
   - Supplement Stack (inkl. Timing)
   - Recovery Guidelines
5. Client erhält alles in der App → Startet
```

## Workflow 2: Wöchentlicher Check-In

```
1. Auto-Reminder: "Zeit für dein Weekly Check-In"
2. Client füllt aus:
   - Gewicht, Fotos, Maße (optional)
   - Wie war Training? (Compliance %)
   - Wie war Ernährung? (Macro Adherence %)
   - Supplement Compliance
   - Subjective: Energy, Mood, Soreness (1-10)
   - Besondere Vorkommnisse
3. Coach sieht Dashboard:
   - Training Compliance: 85%
   - Nutrition Compliance: 72%
   - Supplement Compliance: 60%
   - Recovery Score Trend: 71 → 65 → 58 (↓ Warning!)
   - Weight Trend: -0.5kg/Woche (on track)
   - Strength: Bench +2.5kg (PR!)
4. Coach adjustiert Plan basierend auf Daten
5. Coach sendet Feedback-Message
```

## Workflow 3: Bodybuilding Prep Coach (Enhanced)

```
1. Client im Contest Prep (16 Wochen out)
2. Coach monitored wöchentlich:
   - Body Weight + Composition
   - Macro Adherence (hohe Compliance critical)
   - Training Volume + Intensity
   - Recovery Score (MUSS hoch bleiben)
   - Sleep Data (HRV, Duration)
   - Bloodwork (alle 4-6 Wochen):
     - Hormone Levels
     - Liver/Kidney (wenn Enhanced)
     - Hematocrit (wenn TRT/AAS)
     - Lipids
   - Enhanced Protocol:
     - Current Compounds + Dosierung
     - Side Effects Tracking
     - PCT Planning
   - Supplement Stack:
     - Liver Support (TUDCA, NAC)
     - Cardiovascular (Fish Oil, CoQ10)
     - Performance (Creatine, Citrulline)
   - Posing Practice Schedule
3. Coach sieht Lumeos Dashboard:
   - "⚠️ Client Hematocrit 51% (Week 8 Bloodwork) → steigende Tendenz"
   - "⚠️ Recovery Score 3 Tage unter 50% → Overtraining Risk"
   - "✅ Weight on track: -0.6kg/week"
   - "⚠️ Protein intake nur 1.4g/kg letzte 3 Tage"
4. Coach sendet angepasste Empfehlungen
```

## Workflow 4: Program Auto-Delivery

```
1. Coach erstellt 12-Wochen-Program
2. Setzt Auto-Delivery: Woche 1 → sofort, Woche 2 → in 7 Tagen etc.
3. System liefert automatisch neue Woche
4. Auto-Messages: "Neue Woche freigeschaltet! Fokus: Push Hypertrophy"
5. Coach muss nur reagieren wenn Client Fragen hat oder Daten auffällig
```
