## Purpose

This index organizes current Frontdoor working areas by topic group. Topic folders are current draft work areas, not raw legacy dumps.

## Legacy Boundary

Raw legacy material belongs in:

- docs/project/frontdoor/legacy/

Legacy is a root-level untrusted source area. Topic folders contain current notes, summaries, product intents, spec candidates, workorder drafts, approvals, review packets, decisions, and TODO drafts.

Topic outputs can be derived from legacy analysis only through Frontdoor review and promotion.
