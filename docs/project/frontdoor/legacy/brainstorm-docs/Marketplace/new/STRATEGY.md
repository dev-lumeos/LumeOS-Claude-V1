# Marketplace Module — Strategie & Markt

## Markt-Landscape

**8 Platforms analysiert** — Fitness Digital Products: ~$15B (2025), +20% YoY

| Platform | Stärke | Schwäche |
|---|---|---|
| **Boostcamp** | Kostenlose Top-Programmes (Jeff Nippard), Community | Nur Training, Monetarisierung unklar |
| **TrainHeroic** | Coach-to-Athlete Marketplace, $15–30/mo | Nur Training, keine Nutrition |
| **Eat This Much** | AI Meal Plan Generator, $9/mo | Keine Training-Integration |
| **Future** | $149/mo Premium Coaching — beweist hohe Zahlungsbereitschaft | Teuer, 1:1 nicht skalierbar |
| **Gumroad** | Fitness-Creator verkaufen PDFs/Spreadsheets | Generisch, keine App-Integration |

---

## Kritische Markt-Lücken

1. **KEIN Marketplace verkauft Cross-Module Bundles** — "Training + Meal Plan + Supplement Stack" existiert nirgendwo als integriertes Paket
2. **Kein In-App-Kanal für Supplement Brands** — Brands können aktive Fitness-User nicht "in context" erreichen
3. **Programme sind PDFs oder isoliert** — Boostcamp/TrainHeroic sind in eigenen Apps gefangen
4. **Creator Economy wächst explosiv** — Fitness Influencer suchen Monetarisierung jenseits Ads

## User Personas

### Creator Chris — Fitness Influencer (40%)
- **Pain:** Verkauft PDFs über Gumroad, keine Tracking-Integration, viel Support
- **Needs:** Program Builder, Analytics, Reviews, Low Support Overhead
- **Revenue Expectation:** $2K–10K/mo passives Einkommen
- **Akzeptiert:** 20% Revenue Share (Gumroad 10%, aber keine Integration)

### Buyer Ben — Fitness-Enthusiast (35%)
- **Pain:** YouTube Overload, PDFs nervig, weiß nicht wem er vertraut
- **Needs:** Curated Programs, In-App Integration, Reviews, Progress Tracking
- **Zahlungsbereitschaft:** $15–30/mo für gutes Programm

### Brand Manager Bella — Supplement Brand (15%)
- **Pain:** Kann aktive Gym-Goer nicht in-context erreichen, Instagram Ads zu breit
- **Needs:** In-App Product Placement, "Empfohlen für deinen Stack", Affiliate Dashboard
- **Zahlungsbereitschaft:** CPA $5–15 (vs. Instagram CPA $20–30)

### Coach Diana — Lumeos Coach (10%)
- **Pain:** 1:1 Coaching skaliert nicht, will passive Income aus Templates
- **Needs:** Template → Marketplace, Client Reviews, Upsell zu 1:1
- **Akzeptiert:** 10–20% Commission

## Key Design-Entscheidungen

| Entscheidung | Rationale |
|---|---|
| LIVE Integration statt PDF | Massiver UX-Vorteil. Keine andere Platform kann das. Fortschritt wird in App getrackt. |
| Cross-Module Bundles | Nur möglich weil Lumeos alle Module hat. Premium-Pricing ($49–80). Killer Feature. |
| Wallet = Voucher-System | Kein E-Geld, keine E-Geld-Lizenz nötig. Retention-Booster ("ich hab noch €35 im Wallet"). |
| 80/20 Discovery Split | Besser als App Store (70/30). Fair weil Lumeos Kunden bringt UND Integration liefert. |
| Paid Boost Ranking | "Visibility = Paid" — wie Google Ads, Amazon Sponsored. Transparentes Modell. |
| Buddy als Transaction Gateway | AI-empfohlener Kauf → kürzestes Reibung. User bestätigt nur noch. |
| Brand Placement als B2B Layer | Einzigartiger Kanal: aktive Gym-User die gerade Supplements tracken = perfekte Audience. |
