# Enhanced Supplements — Interaction & Risk Matrix

## Gefährliche Kombinationen (🔴 Critical Alerts)

### Hepatotoxizität (Leber)
| Kombination | Risk Level | Warnung |
|------------|-----------|---------|
| 2+ orale AAS gleichzeitig | 🔴 CRITICAL | "Zwei hepatotoxische orale Steroide = extremes Leberrisiko" |
| Orales AAS + Alkohol | 🔴 CRITICAL | "Alkohol + hepatotoxisches Steroid = Leberschaden" |
| Orales AAS + Paracetamol/Acetaminophen | 🟠 HIGH | "Beide belasten die Leber, kombinierte Toxizität" |
| Orales AAS ohne TUDCA/NAC | 🟠 WARNING | "Leberschutz empfohlen: TUDCA 500mg + NAC 600-1200mg" |

## Bloodwork Schedule Template

### Standard AAS Cycle (12-16 Wochen):
```
Week -2:    Full Pre-Cycle Panel (Baseline!)
Week 6:     Mid-Cycle Panel (Liver, Lipids, Hematocrit, E2)
Week 12:    If >12 weeks → repeat Mid-Cycle
Week 16+2:  Post-Cycle (before PCT start, check clearance)
PCT +4:     Recovery Panel (LH, FSH, Total T, E2)
PCT +8:     Final Recovery Check
```

### TRT (ongoing):
```
Month 1:    Baseline
Month 3:    First Follow-Up (dial in dose)
Month 6:    Comprehensive Panel
Every 6mo:  Ongoing Monitoring
```
