# Supplement Evidence Tiers — Lumeos Reference

## Tier System (ISSN / Examine.com basiert)

### Tier S — Strong Evidence (Must-Have für Athleten)
| Supplement | Dose | Timing | Effect | Evidence Level |
|-----------|------|--------|--------|---------------|
| **Creatine Monohydrate** | 3-5g/Tag | Jederzeit | Kraft ↑, Muskelmasse ↑, Recovery ↑ | ★★★★★ (300+ Studien) |
| **Whey Protein** | 20-40g/Serving | Post-Workout oder Mahlzeit | MPS ↑, Muskelaufbau ↑ | ★★★★★ |
| **Caffeine** | 3-6mg/kg | 30-60min Pre-Workout | Performance ↑, Ausdauer ↑, Fokus ↑ | ★★★★★ |
| **Vitamin D** | 2000-5000 IU | Morgens mit Fett | Knochen, Immunsystem, Testosteron | ★★★★★ |

## Interaction Warnings (Critical)

| Combo | Severity | Issue |
|-------|----------|-------|
| Calcium + Iron | 🟡 Moderate | Calcium blocks iron absorption — take 2h apart |
| Zinc + Copper | 🟡 Moderate | High zinc depletes copper — supplement both |
| Magnesium + Zinc | 🟡 Moderate | Compete for absorption — take at different times |
| Caffeine + Melatonin | 🟠 High | Counteract each other — 8h apart minimum |
| Vitamin D + K2 | ✅ Synergy | Take together for calcium routing |
| Iron + Vitamin C | ✅ Synergy | Vitamin C increases iron absorption |
| St. John's Wort + SSRIs | 🔴 Dangerous | Serotonin syndrome risk |
| St. John's Wort + Birth Control | 🔴 Dangerous | Reduces contraceptive efficacy |
| Blood thinners + Omega-3 | 🔴 Dangerous | Increased bleeding risk |
| Blood thinners + Vitamin K | 🔴 Dangerous | Counteracts anticoagulant |
