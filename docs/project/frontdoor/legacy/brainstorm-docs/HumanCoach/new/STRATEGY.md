## Kritische Markt-Lücken

1. **KEIN Coach-Tool hat echte Nutrition-Tiefe** — alle haben "Meal Plan PDF" oder basic Macros, keine 138 BLS-Mikronährstoffe
2. **KEIN Coach-Tool hat Bloodwork/Medical Integration** — Coach sieht Klientens Bluttest nicht
3. **KEIN Coach-Tool hat Recovery/HRV Insights** — Coach weiß nicht ob Klient erholt ist
4. **Supplement Management fehlt überall** — Coach kann keine Stacks für Klienten verwalten
5. **AI Clone Demand bewiesen** — Coachvox: Coaches zahlen $99/mo um ihre Methode zu skalieren

## Coach Personas

### Coach Alex — Solo Online Coach (40%)
- **Profil:** 30J, 20–50 Clients, arbeitet allein
- **Pain:** 3+ Apps für Training/Nutrition/Chat, keine einheitliche Client-Übersicht
- **Needs:** All-in-One Dashboard, Template-basierte Programmierung, Automated Check-ins
- **Zahlungsbereitschaft:** $49/mo

### Coach Studio — Gym/Studio (25%)
- **Team:** 5 Coaches, 200+ Clients
- **Pain:** Jeder Coach nutzt andere Tools, keine Standardisierung
- **Needs:** Multi-Coach Management, Shared Templates, Client Handoff
- **Zahlungsbereitschaft:** $199/mo

### Influencer Coach — Content Creator (20%)
- **Profil:** 27J, 10K+ Followers, will skalieren
- **Pain:** Will Programme verkaufen ohne tiefe 1:1 Beziehung
- **Needs:** Template Programs, Marketplace Listing, AI Clone
- **Zahlungsbereitschaft:** $99/mo

### Klient Maria — Coached Athlete (60% der Clients)
- **Pain:** Muss Daten in Coach-App UND eigene Tracking-App eingeben (Doppelarbeit)
- **Feature-Needs:** Single App (Lumeos) für alles, Coach sieht automatisch was sie trackt

## Lumeos Coach USPs

### Primary USP: "The Only Coaching Platform Where You See Everything — Training, Nutrition, Recovery, Bloodwork, Supplements — in One Dashboard"

Trainerize zeigt dem Coach: Workouts + basic Macros.
Lumeos zeigt dem Coach:
- Training: Volumen, PRs, Muscle Balance, Progressive Overload
- Nutrition: Macros + 138 BLS Mikronährstoffe + Mahlzeiten-Log
- Recovery: Recovery Score, HRV, Sleep, Muscle Readiness
- Supplements: Stack, Adherence, Interaktionen
- Medical: Bloodwork Trends, Medications (wenn geteilt)
- Goals: Phase, TDEE, Adherence Rate, Trajectory

### Secondary USPs

1. **Kein Doppel-Tracking** — Client nutzt Lumeos → Coach sieht automatisch alles
2. **AI Clone** — Coach's Methode 24/7 skaliert ($99/mo Add-On, Coachvox-Beweis)
3. **Automated Insights** — System flaggt Probleme, Coach reagiert
4. **Marketplace** — Programme einmal erstellen, 1000× verkaufen

## Key Design-Entscheidungen

| Entscheidung | Rationale |
|---|---|
| Client App = Lumeos App | Kein Doppel-Tracking. Coach sieht automatisch alles. Game Changer. |
| Permission-Based Access | Medical Data sensitiv. Client kontrolliert was Coach sieht. GDPR-konform. |
| AI Clone als Premium Add-on | Coachvox validiert $99/mo. Near-zero marginal cost. Starkes Revenue-Potential. |
| Read-only Coach | Client-Ownership. Coach schlägt vor, Client entscheidet/bestätigt. |
| Automated Check-ins | Coaches verbringen 30% ihrer Zeit mit Datensammlung. Auto zieht Weight, Recovery, Adherence. |
| Marketplace Integration | Programme LIVE in der App (nicht PDF). 80/20 Revenue Split. |
