## OpenClaw Rule

OpenClaw may later research, search, summarize, and deconstruct this folder. OpenClaw outputs from legacy must be written as draft analysis or summary artifacts, not as SSOT.

OpenClaw must not promote legacy content directly to specs, TODOs, queue, or workorders.

## Promotion Rules

Legacy material can only become current product truth through:

1. analysis
2. summary
3. source refs
4. drift check
5. documentation_impact
6. approval
7. promotion into product intent, spec candidate, or workorder draft
